本次检查针对 2026-10-21 的开发源码。源路径星号和跨主机下载修复晚于已发布的 0.7.0 安装包。对照依据为 [OpenSSH scp 官方手册](https://man.openbsd.org/scp)。

| 能力 | bcmr 当前情况 |
|---|---|
| 上传、下载、多源、递归目录 | 已有。多个下载源要求目标是现有目录或显式以 `/` 结尾；不同主机的源使用逐源保留主机信息的传统 SSH 通道。 |
| 源路径通配 | 支持本地和远程 `*`，不实现其他模式操作符。 |
| SSH 别名、端口、密钥、跳板机、地址族、加密算法 | 可通过正常的 SSH 配置使用，缺少临时 CLI 覆盖入口。`--config` 是 bcmr 配置，`-P` 是传输并发数。 |
| 密码和密钥口令认证 | 交互式传统 SSH 通道可使用原生提示；serve 连接使用批处理认证，无法认证时可能回退。 |
| IPv6 | 支持 `[::1]:file` 形式。 |
| 文件属性和压缩 | 已有 `-p`、线缆压缩和 SSH 压缩配置；根、子目录和空目录在内容完成后保存普通属性。 |
| 远程到远程复制 | 尚缺，当前需本地中转。 |
| 仅开放 SFTP 的受限账号 | 尚缺；serve 和回退通道都需要执行远程命令。 |
| `scp://` URI 和路径内端口 | 尚缺；请使用 `[user@]host:path`，端口放在 SSH 配置中。 |
| 带宽限速 | 尚缺；并发数不等于限速。 |
| 递归符号链接 | 复制默认跟随目录链接并检测循环；本地和远程 `--no-deref` 保留链接，移动保留链接本身。 |
| 本地和远程混合源下载到本地 | 传输前明确拒绝，请分开执行。 |

传统回退实际上使用系统 SSH 和远端 `cat`、`stat`、`find` 等命令，并非旧 SCP 线缆协议或 SFTP 客户端。serve 协议不兼容导致的回退，与源路径是否含星号相互独立。

默认不覆盖、覆盖确认、拒绝远程 `..` 和裸文件系统根路径属于有意的行为差异，不计作缺少功能。bcmr 另外提供校验、断点续传、预演、多目标分发和 JSON 事件等工作流。

## 哪些能力值得继续做

临时 SSH 参数值得实现。一次性访问非默认端口、临时密钥或跳板机时，要求先改持久配置不方便；已有 SSH 配置能力不能完全代替一次调用的覆盖入口。建议新增清楚的长选项，例如 `--ssh-port`、可重复的 `--ssh-identity`、`--ssh-config` 和 `--ssh-jump`，保留 `-P` 的传输并发含义。**这些是后续接口建议，当前尚未提供。**

它们应共用一个连接参数对象，在通配展开之前初始化，并覆盖 serve、传统传输、预检、移动清理、部署和诊断等所有路径。端口、密钥、跳板机改变时不能继续复用旧的 ControlMaster 身份。密钥参数并不意味着只尝试这一把密钥；是否使用其他配置或 agent 身份仍遵循 [OpenSSH 认证配置](https://man.openbsd.org/ssh_config.5)。不需要提供可拼接任意命令的 `--ssh-command`。

| 后续能力 | 判断与优先级 | 需要解决的问题 |
|---|---|---|
| 临时 SSH 参数 | 高，适合下一项实现 | 所有连接路径共用参数；补全与后台任务也需传递；避免复用错误的连接。 |
| 聚合带宽限速 | 高，适合共享服务器和受限链路 | 应约束全部并发连接的总速率，明确单位和计量范围，不能简单给每个 worker 同一上限。 |
| `scp://` 与 URI 端口 | 中，主要改善兼容与脚本迁移 | 端点端口、编码路径、IPv6 解析及连接池身份必须贯通，不应仅去掉 URI 前缀。 |
| 本地与远程混合源 | 中，便利性改进 | 同一计划内保留每个源的主机、冲突检查、进度与移动清理规则。当前明确拒绝比漏传部分源安全。 |
| 远程到远程 | 有必要，独立实现 | 优先经本地客户端有界流式中转；两端取消、校验、暂存发布和移动清理必须协调。无需把目标机密钥放到源服务器。 |
| SFTP-only 账号 | 若要覆盖常见 scp 使用范围，就有必要 | 需要真正的 SFTP 后端，包括遍历、属性、传输与错误处理。现有远程 exec 通道无法靠增加一个 SSH 选项满足。 |

其余缺口都有合理用途，但不应把它们都当成同一轮小修复。正确性优先；随后实现共用 SSH 参数和限速，再根据实际部署需求建设中转或 SFTP 后端。无需为了复刻 scp 而复制它的全部历史短选项。
